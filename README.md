# VeriAcademia

A verified university research portal for traceable publications, patents, researcher profiles, and controlled access.

## Current phase

The initial Next.js UI foundation preserves the original homepage design and establishes the monorepo structure. The 17 product specification documents are in `docs/`.

## Run locally

```bash
corepack enable
pnpm install
pnpm --filter web dev
```

Open http://localhost:3000.
